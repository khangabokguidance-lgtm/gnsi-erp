How sets are made

  • The same set number always gives the same questions, so you can reprint it later.
  • Booklet codes B, C and D shuffle the question and option order of that set. Each code has its own answer key.
  • Figure and arithmetic questions are drawn fresh for every set number.
  • Each set follows the JNVST syllabus: all 10 Mental Ability types (or the 5 of your sample paper), every Arithmetic topic, EVS and four reading passages.

Import questions from a PDF or photos

Upload a question paper as a PDF, or photos of its pages. AI reads its EVS, Arithmetic and reading-passage questions. Check them, fix any answer, and add the ones you want. Figure questions are left out, because new ones are drawn for every set.
